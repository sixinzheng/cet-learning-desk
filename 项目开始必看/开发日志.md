## 七、已知问题 & 坑（接手必看）

1. **5400 端口旧进程**：werkzeug 在 Windows `SO_REUSEADDR` 下可双进程绑定同一端口，新路由请求落到旧进程 → 404。排查：`netstat -ano | grep :5400`，见多 PID 就 `taskkill //PID <pid> //F` 后干净重启
2. **DB 位置**：`data/vocab.db`，不是 `instance/vocab.db`
3. **静态资源缓存**：Jinja 全局 `asset(filename)`（app.py），按 mtime 出 `?v=`；改 JS/CSS 刷新即拿新版，勿手写 `?v=N`
4. **设计 token 是契约**：`test_site_contract.py` 断言 `--paper #f5f0e7` 等；改布局前先跑它，且必须先用设计 skill（`ui-ux-pro-max`）定方案
5. **非 git 仓库**：无版本历史，改前先备份到 `.backup-YYYY-MM-DD-*/`
6. 听力用浏览器 TTS（非真人发音）
7. **新旧计分并存**：段位能力计分读新版 `/api/practice/*/complete`（practice_sessions），投入维度仍消费旧 `/api/study/log-*`
