# 四六级学习台 v0.3.3

这是 Android 首次启动故障的紧急修复版本。

## 修复内容

- 修复 v0.3.2 Android 安装包缺少本地题库和站点资源、首次启动显示 `FileNotFoundException` 的问题。
- Android 发布构建改用发行种子库校验离线发音资源，不再依赖不会提交到仓库的开发数据库。
- 资源准备、Gradle 构建或 APK 内容校验任一步失败时立即终止发布，避免再次生成只有应用外壳的安装包。
- 签名前直接检查 APK 内的种子题库、资源清单和离线发音包，并核对与发行源文件的 SHA-256。

## 数据与升级

- 可直接覆盖安装 v0.3.2，Android 应用数据、学习记录、笔记和 API 配置保持不变。
- 本次不修改题库内容、学习规则、复习调度、六维段位算法和界面布局。
