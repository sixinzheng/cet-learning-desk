# 四六级学习台 v0.3.5

## 安全更新修复

- Android 更新检查优先使用固定发布清单，GitHub API 暂时不可用时仍可回退检查。
- APK 下载支持断点续传、网络重试和退避，读取超时提高到 120 秒；页面会显示下载进度、重试次数和当前阶段，不再直接暴露英文异常。
- 继续严格校验文件体积、SHA-256、包名、版本号和签名证书；错误清单、错误续传响应或错误签名均不会进入安装。
- 已安装旧更新器的 Android 用户需先手动安装本版本同签名 APK，之后即可使用新的断点续传更新能力。

## 同一 Wi-Fi 设备同步

- Windows 与 Android 可通过“我的 → 设备同步”创建一次性配对会话，用二维码或完整配对码在同一 Wi-Fi 下双向合并学习数据。
- 同步使用临时 TLS 证书、证书指纹固定和 256 位一次性令牌；会话完成、取消或十分钟超时后立即关闭局域网服务。
- 同步前双方分别生成 SQLite 在线备份并校验，使用稳定 UUID、删除墓碑和学习事件去重，避免重复同步造成记录累加。
- 笔记与 AI 正文并发冲突时保留双方并生成明确的冲突副本；DeepSeek API Key、会话密钥、更新缓存和本机路径永不进入同步包。

## 学习与阅读体验

- 桌面端文章列表改为有限高度的品牌色滚动区，切换文章时自动保持当前项可见；手机端继续使用自然页面滚动。
- 手机尚未设置训练难度时，每次进入学习页都会提醒，可选择稍后处理，或一键定位并聚焦难度选项。
- 延续 v0.3.4 的移动成长图表、背词答后定位、滑动标注、词汇掌握标色与词表弹窗、AI 词义补全及隐藏缓存词库能力。

## 数据安全

- 更新和同步失败均不会把未校验内容写入正式数据；发行种子继续清除个人学习记录、笔记、AI 对话、设置和密钥。
