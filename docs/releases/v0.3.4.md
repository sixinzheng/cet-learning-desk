# 四六级学习台 v0.3.4

## 阅读与背词体验增强

- 修复手机成长页柱状图挤压、标签和刻度重叠，词汇成果、专项训练与学习节奏在窄屏下改为单列全宽展示。
- 手机背词答题后自动回到学习卡顶部，方便立即查看答案和继续操作；桌面端保持原有滚动位置。
- 阅读页支持吸顶标注工具栏、再次点击退出模式，以及鼠标和手指连续涂抹标注。
- “本文词汇掌握”支持正文状态标色与本文词表弹窗，可查看待掌握/已掌握单词并直接收藏。
- 查词增加常见词形还原；未收录词可按需使用 AI 补全，已有词可使用 AI 完善。生成结果按单词缓存，重复查词不会重复计费。
- 新增隐藏的“阅读词汇缓存”词库，发行数据不会把该内置词库暴露到普通词库选择和学习队列。

## 手机阅读布局

- “查看题材参考”和“来源与原创说明”在手机端同行排列。
- 字号控制居中显示，并保留不小于 48px 的触控区域。

## Windows 桌面端持久化修复

- 修正 Windows 主程序的 GUI 子系统配置，启动时不再打开终端窗口。
- 桌面后台改用稳定的本地端口，确保新手引导、阅读字号、头像等 WebView 本地状态可跨启动保留。
- 已存在的用户数据库不会被安装包内的发行种子覆盖；快速重启时会等待旧后台释放端口。
- 发行种子继续执行隐私清洗，不包含发布者的学习记录、笔记、AI 对话、设置、API Key 或自建内容。
