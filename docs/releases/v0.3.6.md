# 四六级学习台 v0.3.6

## 设备同步可靠性

- 局域网同步协议升级为 v2，电脑和手机均完成数据准备、正式落库和完整性校验后才显示成功。
- 词汇状态、收藏、词库、学习与复习记录、阅读标注、设置、笔记和 AI 内容按稳定记录标识合并；断线重试不会重复累计学习数据。
- 同步完成后两端显示同一份结果报告，列出段位、掌握词数以及各类数据的实际新增、更新、删除和冲突数量。
- 手机最终写入或确认失败时，电脑继续显示等待确认或可恢复状态，不会提前报告成功。

## 手机界面优化

- 控制页移除手机端冗长页头，工具栏整理为“笔记、当前笔记、中、EN”单行布局，聊天区充分使用剩余屏幕高度。
- 手机“我的”页收起介绍文字，保留紧凑的段位档案入口；桌面版完整页头保持不变。
- 修复主要页面中短标题、统计指标、按钮及数值单位出现单字孤行的问题。
- 语言切换和页面定位尊重系统“减少动画”设置，主要触控按钮继续保持不小于 48px。

## 数据安全

- 同步前继续创建双方数据库备份并执行完整性检查，未确认的暂存结果不会替换正式数据库。
- DeepSeek API Key、加密密文、会话密钥、本机路径、更新缓存和临时任务不会进入同步数据包或发行种子。
- Windows 与 Android 安装包继续使用既有发布密钥签名，正常覆盖升级会保留现有本地学习数据。
