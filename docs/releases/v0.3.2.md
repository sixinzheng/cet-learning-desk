# 四六级学习台 v0.3.2

这一版集中修复学习主流程、移动端引导与首页数据口径，并补齐可离线使用的统一发音资源。

## 主要更新

- 单词学习改为“每日稳定乱序”：同一天刷新顺序不变，次日自动重新洗牌。
- 新增本站统一美式发音资源与索引，覆盖 12,933 个词及固定听力材料；浏览器或 Android 不支持系统发音时仍可播放。
- 修正首页“已新学、今日还需新学、待学新词、到期复习、词库未稳定掌握”等数据口径，按钮、建议和数据格使用同一组统计结果。
- 修复首页段位人物头像裁切，人物头部、发冠和主体在桌面与手机端完整显示。
- 首次启动增加欢迎页，并在“我的 → 新手指引”中支持随时重新查看；移动端引导正文可滚动、底部按钮始终可见。
- 首页、控制台和笔记页共享中文／English 助理偏好，英文模式与预设场景保持同步。
- 修复阅读页桌面目录空白、手机字号按钮失效，以及写作批改桌面端栏宽和图片上传控件错乱。
- 完善 Windows 源码快捷启动诊断与日志，减少端口、Python 或依赖异常造成的无提示启动失败。
- README 增加四张当前版本真实运行截图。

## 数据与升级

- 覆盖安装会保留用户数据库、学习记录、笔记、AI 配置和历史段位。
- 不修改背词判定、艾宾浩斯复习调度、学习记录口径和六维段位算法。
- 发音包在发布构建时校验版本与 SHA-256，并随 Windows、Android 安装包提供。

- 阅读与写作桌面／手机浏览器审计通过。
