# 四六级学习台 v0.3.1

这是 v0.3.0 的安全修正版，重点修复 Android 首次启动与覆盖升级可靠性，并完善“我的 → 安全更新”和 AI Skill 折叠管理。

## Android 用户请注意

- Android v0.3.0 因资源导入缺陷无法正常启动，也无法在应用内自行检查更新。
- 请从本 Release 手动下载 v0.3.1 APK，并直接覆盖安装；不要先卸载旧版。
- v0.3.1 保持原包名和原发布签名，覆盖安装会保留应用私有数据库和已保存的 API 配置。
- Android 0.2.0 及更早版本同样需要手动覆盖安装一次 v0.3.1。

## 本次更新

- 修复 Android 缺少 `seed` 阅读资源导入路径导致的启动失败。
- 加固 Android Keystore 配置落盘，避免保存成功提示与立即升级之间的竞争。
- 新增“我的 → 安全更新”：用户主动检查稳定版，安装前先创建并校验 SQLite 备份。
- Windows 更新继续使用 Tauri 签名校验；Android 同时核对 HTTPS 来源、SHA-256、包名、递增版本号和原签名证书。
- AI Skills 整区默认收起，展开后使用单项手风琴，减少设置页纵向长度。

## 数据保护

- 更新前使用 SQLite Online Backup 创建一致性副本，并执行 `PRAGMA quick_check`。
- 备份、下载、哈希、签名或版本校验失败时会停止安装，不修改现有数据库。
- 源码运行模式只显示稳定 Release，不会执行 `git pull` 或覆盖开发工作区。

## 已验证

- Windows v0.3.0 → v0.3.1 隔离更新后，学习数据、配置和凭据保持不变。
- Android 真机同签名覆盖安装后，SQLite 数据和 Android Keystore 配置保持不变。
- Android 系统拒绝了错误签名 APK 和版本号倒退 APK。
