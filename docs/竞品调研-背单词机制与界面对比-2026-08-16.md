# 竞品调研：背单词机制与界面对比（2026-08-16）

> 目的：调研 GitHub 上与我们「四六级单词助手」类似的权威项目，重点看它们的背单词界面与调度机制，并逐项对比差异。
> 方法：5 个并行调研代理，其中 Anki、Engram、Qwerty Learner、duocards 等做了源码级通读；墨墨/不背不开源，以官方文档+第三方拆解为准。我方机制取自 `services/review_service.py`、`static/js/study.js`、`static/js/review.js` 实读。

## 四、逐项目要点

### 1. Anki —— 间隔重复行业标准
- **界面**：卡片翻转后底部四键 **Again/Hard/Good/Easy**（快捷键 1/2/3/4），每键下方显示预期间隔（可关闭）；牌堆列表用蓝/红/绿三色数表示「今日新增/学习中/到期复习」负载。
- **机制**：新卡先走**学习步骤**（默认 1m 10m，串行步进，Good 前进、走完毕业为复习卡）；复习卡间隔由 **ease** 驱动——Again −0.20 重置 1 天、Hard ×1.2、Good ×(ease+迟到补偿 delay/2)、Easy ×1.3 bonus，外加 **fuzz 随机抖动**防扎堆。ease 下限 130%。
- **状态机**：New→Learning→Review→Relearning；复习卡 Again 判定 **lapse**（重学+间隔重置）；lapse 累计 8 次打 leech 标签并挂起。
- **下一代 FSRS**（2025-07 起默认）：DSR 三参数（难度/稳定性/可提取性）+ 21 个训练参数，目标保留率默认 90%，同保留率比 SM-2 少 20~30% 复习量。需 ~1000 次复习才稳定，小站不适用。

### 2. Qwerty Learner —— 最热门的网页背词
- **界面**：逐字母打字，打对变绿、打错变红、整词清空 300ms 重打；音标(美/英)、释义、发音、底部进度条；**默写模式**（隐藏全部/元音/辅音/随机）很完善。
- **机制**：**完全没有间隔重复/艾宾浩斯调度**。按章节线性刷词（20 词/章）；唯一"复习"是**错词本**——按「错误次数×0.6 + 最近错误时间×0.4」加权排一次性回顾列表。无记忆状态机。

### 3. Engram —— 最接近我们定位的桌面应用
- **界面**：分组 batch（5~30 词可设），新词与到期复习词**混批打乱**；三键 不认识(红)/模糊(黄)/认识(绿)，快捷键 1/2/3；全键盘操作、刻意剥离游戏化（无金币/连击）。
- **机制**：6 档固定阶梯表 **10m→1d→3d→7d→15d→30d**；认识→新词直入 stage1、旧词一次 +2 格；不认识→**一步清零回 stage0**；**单次评分即推进，无连对**；批内可**重评分覆盖**（反悔纠错）。
- **与我们差异最大点**：激进速通（答对涨得快、答错跌得狠），我们则是保守五态（连对把关+连错降级+每天一格）。

### 4. 墨墨背单词 —— 算法派标杆（闭源）
- **算法**：SSP-MMC（KDD'22 论文），放弃通用艾宾浩斯曲线，为**每个词/每个用户**独立拟合遗忘曲线 R=0.9^(t/S)，引入记忆稳定性 S、单词难度 d（10 级）、用户记忆能力 MRL；间隔上限 **365 天**。目标是最小复习成本达到目标半衰期（论文示例 360 天）。
- **界面**：复习/选词/统计/设置 4 tab；看词**先只显示英文主动回忆中文**；标「不确定/不认识」的词**隔 4~5 个词即时复现**；每日量算法规划、用户只调总量。
- **对自研小站的启示**：个性化需要千万级用户数据拟合，**单个小站无法复刻**；固定间隔表的「确定性、可解释、无冷启动」反而是小产品正确的取舍。

### 5. 不背单词 —— 语料派标杆（闭源）
- **核心壁垒**：150 万+ 原声例句（影视/纪录片/外刊）检索，不是算法。
- **学习机制**：新词**连对 3 次（10/15 词组）或 4 次（20 词组）才过，中途答错立即清零从头学**——与我们学习板块的「连对 3 过关」几乎一致；复习评分后间隔算法化，**>100 天判已掌握**（比墨墨 365 天激进）。

### 6. 开源 SRS 应用群要点
- **duocards**：答对间隔 ×2.5、答错 ×0.25；错后折算 <1 天则退回学习阶段从 1 分钟重来。学习步骤 1m/10m/1d。
- **vocabulary-mcp**：经典 SM-2 **0~5 六档质量评分**（细粒度反馈）。
- **Muse**：SM-2 + AI；**「快速复习」绕过算法一键全量复习** + 「今日回顾」侧边栏——给用户脱离调度器的出口。
- **WordPow**：FSRS v5；**Kahoot 式游戏化 + 连击/XP/等级/正确率**激励。
- **Langner**：硬编码间隔 **7/30/90/365/1000 天**；**错词必复现直到答对**；三种方向测验（看词打义/看义打词/自由回忆）+ 同词源成卡 + 批次反馈页。
- **google/bespoke**：**句子级卡片**（整句含词，非孤词）+ **接受性(听读)/表达性(说写)技能分开调度**，利用「交叉影响」。

## 五、与我们最接近/最值得对照的

1. **机制上最接近**：**不背单词**（学习连对 3 清零重学 + 艾宾浩斯改良）——我们用代码把「连对 3」做成了硬机制，与不背理念一致。
2. **结构上最接近**：**Engram**（同为「固定间隔表 + 多状态」确定性调度，专为 CET 设计）——但它激进（一次 +2/一步清零），我们保守（连对把关+每天一格+连错降级）。
3. **学术上最权威**：**Anki**（四档评级 + 学习步骤 + ease 动态 + fuzz）与**墨墨**（逐词个性化）——是我们固定间隔表往上走的两个方向。

## 六、可借鉴清单（按优先级）

**调度机制层（低风险，可直接落地）**
1. **四档评级进复习**（Anki/墨墨）：把现在「记得/忘了」两档扩成「认识/模糊/忘记」（可选「熟记」），模糊=短间隔重现、认识=正常推进、忘记=计数降级。比纯对/错更能精准调度。
2. **当日即时复现**（墨墨）：学习/复习中标「模糊/忘记」的词，**间隔 4~5 个词后当场再抽一次**，而不是等到明天——强化短时记忆。
3. **按词难度分档间隔**（墨墨 MM-1 的核心发现）：固定表同一状态所有词同间隔，忽略难度差异。可把「模糊」态按 `frequency`/难度拆 2~3 条间隔线（易词快、难词慢），不改架构即可逼近个性化。
4. **反馈缩放间隔**（duocards/Langner）：把四档映射为间隔倍率（如认识×1.5、模糊×1.0、忘记×0.5），比纯固定表灵活。
5. **错词必复现兜底**（Langner）：降级后保证该词持续出现在队列直到答对，避免「毕业词永久消失」。
6. **毕业上限对齐**：墨墨 365 / 不背 100 天判掌握，我们 180 天介于其间属合理；可考虑熟记后进入极长间隔（365+）而非硬停。

**界面/交互层（可直接参考）**
7. **按钮显示预期间隔**（Anki）：评级按钮下方显示「下次复习：明天/3天后」等，透明化调度，增强用户信任。
8. **正/反向 + 自由回忆三方向测验**（Langner）：现在复习是「给词选义/听力」，缺「看义打词」产出式方向；Qwerty 的打字 recall 也可作可选模式。
9. **快速复习 + 今日回顾侧边栏**（Muse）：调度器之外给用户一个「自主全量复习」出口，避免错过到期就荒废。
10. **批次反馈页**（Langner/不背）：每批结束展示正确释义+例句+发音+错题回顾，而不只是 toast。
11. **游戏化激励（可选）**（WordPow）：连击/今日进度/正确率曲线，提升留存；注意 Engram 反方向（去游戏化）说明这是产品取舍。

## 结论一句话

我们项目的五态艾宾浩斯在**确定性、可解释、节奏控制**上是同类里的突出设计（对比 Engram 的激进、Qwerty 的无调度）；主要短板是**固定表忽略难度差异、反馈只分对/错两档、无当日即时复现**。往上走的两条路：① 学 Anki/墨墨做「难度分档 + 反馈缩放间隔」逼近个性化；② 学不背/Langner 做「产出式测验 + 批次反馈页」增强记忆深度。
