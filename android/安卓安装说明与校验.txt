版本：0.2.0

适用系统：Android 7.0 及以上
处理器：arm64-v8a（目前绝大多数安卓手机）
包名：cn.cet.learningdesk

安装方法：
1. 把 APK 复制到安卓手机，或直接让手机读取 U 盘。
2. 点击 APK；若系统提示，请仅为当前文件管理器开启“允许安装未知应用”。
3. 首次打开会解压本地题库，通常需要 10～30 秒，请勿中途关闭。

功能说明：
背词、六维段位 V3、笔记和本地题库在手机本机运行；AI、作文图片识别、余额查询和在线文章来源需要网络及用户自己的 DeepSeek API Key。API Key 使用 Android Keystore 加密。

重要提醒：
当前电脑没有连接安卓真机。本包已通过 APK 结构、arm64 架构、zipalign 和 v2/v3 发布签名验证，但仍需在目标手机完成一次首次启动验收。卸载应用通常会清除本地学习记录，请先导出重要内容。
